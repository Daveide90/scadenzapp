# Security / Sicurezza

**[English](#english)** · **[Italiano](#italiano)**

## English

ScadenzApp has no servers and no accounts: the data stay encrypted on the phone of whoever uses it, and the app has no permission to access the Internet. A security problem therefore concerns the phone itself: for example a way to read the database or a backup without the key or the password, to get around the lock, or a crafted backup file that makes the app close or alters its data.

**How to report it.** Use GitHub's private reporting on this repository (Security tab › Report a vulnerability), not a public issue. Include the app version (Impostazioni › Informazioni su ScadenzApp), the phone model and the steps to reproduce the problem. No real data are needed: a test backup is enough.

**What happens next.** An answer within 7 days. If the problem is confirmed, the fix comes out in a new version and is listed in the [CHANGELOG](CHANGELOG.md) as a security fix. Whoever reported it is credited, if they wish.

**Supported versions.** Only the latest version.

ScadenzApp is a hobby project by a non-professional developer, offered as is: see the [LICENSE](LICENSE).

## Italiano

ScadenzApp non ha server né account: i dati stanno cifrati sul telefono di chi la usa, e l'app non ha il permesso di accedere a Internet. Un problema di sicurezza riguarda quindi il telefono stesso: per esempio un modo di leggere il database o un backup senza la chiave o la password, di aggirare il blocco, o un file di backup costruito apposta che fa chiudere l'app o ne altera i dati.

**Come segnalarlo.** Con la segnalazione privata di GitHub su questo repository (scheda Security › Report a vulnerability), non con una issue pubblica. Indicare la versione dell'app (Impostazioni › Informazioni su ScadenzApp), il modello del telefono e i passi per riprodurre il problema. Non servono dati veri: un backup di prova basta.

**Cosa succede dopo.** Una risposta entro 7 giorni. Se il problema è confermato, la correzione esce in una nuova versione e compare nel [CHANGELOG](CHANGELOG.md) come correzione di sicurezza. Chi segnala viene citato, se lo desidera.

**Versioni seguite.** Solo l'ultima versione.

ScadenzApp è un progetto amatoriale di uno sviluppatore non professionista, offerto così com'è: vedi la [LICENSE](LICENSE).
